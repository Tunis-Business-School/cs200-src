## 📚 About This Repository

Welcome to the official repository for **CS200: Web Development** at Tunis Business School!  
This repo contains all the source code, examples, and activity solutions for the course.  
It is intended as a reference and learning resource for students enrolled in CS200.

---

## 🗂️ Repository Structure

The repository is organized by topic, with each folder prefixed by `01_`, `02_`, etc., corresponding to the course modules.  
Inside each folder, you’ll find example code and solutions for activities.

**Topics covered:**
- **HTML Fundamentals**
- **CSS Basics**
- **CSS Layout**
- **JavaScript Basics**
- **JavaScript: DOM Manipulation**
- **JavaScript: Event Handling**
